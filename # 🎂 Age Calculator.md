# 🎂 Age Calculator

## 📌 Project Description

Age Calculator is a simple Java console application that calculates a person's age using their date of birth.

The program takes the user's birth year, month, and day and calculates the exact age in **years, months, and days**.

## 🚀 Features

* Enter date of birth
* Calculate current age
* Display age in years
* Display age in months
* Display remaining days
* Simple console interface

## 🛠️ Technologies Used

* Java
* `Scanner`
* `LocalDate`
* `Period`
* Java Date and Time API
* VS Code
* GitHub

## ▶️ How to Run

### Step 1: Compile

```bash
javac AgeCalculator.java
```

### Step 2: Run

```bash
java AgeCalculator
```

## 🧪 Test Bench

The project can also include `AgeCalculatorTest.java` to test different birth dates and verify the calculated age.

Compile:


Run:

